Hoth had a shield generator and still fell. You own physical and information security at both sites: access control, visitor management, classified-information handling and security awareness.

1. Run access control, visitor management and site security.

1. Implement classified-information handling (VS-NfD and above).
2. Run security awareness training for all staff.

## Requirements

- Experience as a security officer in defence industry or government.

- Calm, firm and approachable.
- Fluent German and English.
