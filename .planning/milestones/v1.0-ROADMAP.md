## Milestone Summary

**Key Decisions:**
- build-single.mjs delegates to build-all.js via execSync subprocess for correct stdio inheritance
- publish.yml uses WM_PUBLISH_PAT (not GITHUB_TOKEN) for cross-repo push
- Content skills do NOT auto-build — operator runs /wm-publish to go live (D-A6)
- Ingest reads HTML/CSS artifact directly (no Figma intermediate)
- brand block lives in wiring.json (one source of truth per site)
- INGEST-05 scope: CDN fonts auto-injected into Layout.astro; local font copy out of scope for CDN-only artifacts
