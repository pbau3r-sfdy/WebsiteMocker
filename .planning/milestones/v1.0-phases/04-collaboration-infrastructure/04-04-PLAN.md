Two credentials, deliberately distinct:
  WM_PUBLISH_PAT   Classic PAT, `repo` scope.  Lives ONLY in WebsiteMocker Actions secrets.
                   Used by publish.yml and content-sync.yml for checkout, commit-back, and the
                   JamesIves push.
  WM_DISPATCH_PAT  Fine-grained PAT, resource owner pbau3r-sfdy, repository access limited to
                   pbau3r-sfdy/WebsiteMocker, Repository permissions -> Contents: Read and write,
                   1-year expiry. Lives in EACH production repo's Actions secrets.
                   Used by content-ci.yml to POST a repository_dispatch to WebsiteMocker.

Production repo branch model (COLLAB-04):
  main      contributor surface — content/**/*.md, .github/, CONTRIBUTING.md. Default branch.
  gh-pages  built output only. Force-overwritten by every publish. Never hand-edited.

Full loop (COLLAB-05, as decided):
  contributor pushes content/**/*.md to prod main
    -> content-ci.yml dispatches event_type content-updated with {"slug": "<slug>"}
    -> WebsiteMocker content-sync.yml copies *.md into sites/<slug>/src/content/, commits to main,
       writes a job summary — it does NOT build and does NOT publish
    -> operator reviews, then runs /wm-publish <slug> to go live

Existing skill file conventions (from .claude/skills/wm-publish.md and wm-wire.md):
  H1 `# /<skill-name>`, one-or-two-line purpose, `## Steps` with bolded numbered steps,
  fenced bash blocks for commands, closing `## Notes` bullet list. No YAML frontmatter.

Production repos: pbau3r-sfdy/{starflight-dynamics, mogwai-systems, parrot-capital, crestworks}

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-04-19 | Elevation of privilege | documented PAT scope | mitigate | The skill documents exactly one scope — fine-grained, resource owner `pbau3r-sfdy`, single repository `pbau3r-sfdy/WebsiteMocker`, `Contents: Read and write`, everything else "No access" — and includes a `Why not reuse WM_PUBLISH_PAT?` subsection so an operator taking the shortcut meets the consequence rather than guessing |

| T-04-21 | Repudiation | PAT expiry with no owner | mitigate | The 1-year fine-grained cap and its silent-failure mode (contributor push succeeds, dispatch does not) are written into the skill, giving the renewal obligation a durable home instead of living in session memory |
