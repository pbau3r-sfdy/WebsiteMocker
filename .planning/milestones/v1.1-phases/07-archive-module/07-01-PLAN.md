<objective>
Create `_scripts/archive-browse.mjs` — a Node.js CLI that queries the Wayback Machine CDX API, displays a year-grouped snapshot timeline with toolbar-stripped if_ inspection URLs, supports a --sweep mode for multi-domain coverage audits across all active wiring.json domains, and hands off selected snapshots to `capture-site.mjs` via --capture.

Purpose: Give the operator full visibility into a domain's Wayback archive history and a one-command path from timeline inspection to design DNA extraction.
Output: `_scripts/archive-browse.mjs` (single new file, ES module, no new npm packages).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator CLI args → script | `--capture <timestamp>` and slug/domain positional arg cross here; both are unsanitised strings from the terminal |
| CDX API response → script | Array-of-arrays from an external public API; individual timestamp fields could be malformed |
| script → capture-site.mjs subprocess | Shell command string is constructed here; any unsanitised input embedded in this string is a shell injection risk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | `--capture <timestamp>` arg interpolated into execSync command string | mitigate | Validate timestamp against `/^\d{14}$/` before any use in shell command or file path; fail with actionable message if not exactly 14 digits |
| T-07-02 | Tampering | `inputArg` (slug) used to construct wiring.json path and captureSlug passed to subprocess | mitigate | Validate slug against `/^[a-z0-9-]+$/` in `resolveDomain()` before any file access or path construction |
| T-07-03 | Tampering | CDX response row[0] timestamp used in captureSlug and if_ URL construction | mitigate | D-10 check confirms timestamp exists in CDX response before use; timestamp comes from CDX (not directly from operator) so risk is low, but D-10 validation also gates this path |
| T-07-SC | Tampering | npm/pip/cargo installs | accept | No new packages in this phase; CDX uses Node 18+ built-in fetch; slopcheck protocol does not apply |
</threat_model>
