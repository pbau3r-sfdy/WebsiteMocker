_scripts/lib/design-block.mjs
- `DEFAULT_GLOBS` = ['tokens/**', 'templates/website/**', 'ui_kits/website/**', 'components/**', 'assets/logo/**', 'assets/brand/**'] (D-01)
- `isUploadsPath(relPath) -> boolean`: true when the first normalised path segment equals `uploads` case-insensitively (D-02)
- `validateDesignBlock(block, { root }) -> { ok: boolean, errors: string[] }`
- `readDesignBlock(root, slug) -> { block: object|null, errors: string[] }` (block null and errors [] when absent)

Design block shape (in `sites/<slug>/wiring.json` under `design`):
- source `design-system`: `project_id` (UUID shape, required), `name` (string, optional), `globs` (string[], optional, default DEFAULT_GLOBS)
- source `artifact`: `url` (https URL, required)
- source `local`: `path` (repo-relative or absolute, must exist, required)
- any source, optional: `tokenMap` (object `--from` -> `--to` string or null), `allowHosts` (string[] of hostnames)

_scripts/lib/design-lock.mjs
- `hashContent(bufOrString) -> hex sha256`; strings and text buffers LF-normalised (CRLF and lone CR -> LF) before hashing; binary buffers (contain a NUL byte) hashed raw
- `emptyLock(source) -> { version: 1, source, pulledAt: null, revision: null, files: {}, components: {}, tokens: null }`
- `readLock(siteDir) -> lock|null` reads `<siteDir>/design.lock.json`
- `writeLock(siteDir, lock)` writes 2-space JSON, keys of `files` and `components` sorted, trailing newline
- `diffFiles(prevFiles, nextFiles) -> { added, changed, removed, unchanged }` (string arrays, sorted; compare on sha256)
- `checkComponent(lock, name, currentContent|null) -> 'absent' | 'clean' | 'edited' | 'untracked'` (absent: no file on disk; clean: lock hash equals hash of current; edited: lock entry exists and differs; untracked: file exists with no lock entry)
- `recordComponent(lock, name, from, content) -> lock` sets `components[name] = { from, sha256: hashContent(content) }`

design.lock.json shape: `{ version, source: { type, id, name }, pulledAt, revision, files: { "<rel path>": { sha256, bytes } }, components: { "<Name>": { from, sha256 } }, tokens: { sha256 } | null }`

Staging layout (Claude's discretion, fixed here): `_staging/design/<slug>/files/<source-relative path>` holds pulled bytes; optional `_staging/design/<slug>/listing.json` = `[{ "path": "...", "size": <int|null> }]` written by the model from `list_files` when sizes are exposed.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Staged files -> Node scripts | Pulled bytes and file names are untrusted |
| Local zip/dir export -> staging | Operator-supplied archives may contain hostile entry names |
| Lock file -> public repo | Committed metadata is public |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-06 | Information disclosure | `design-stage.mjs` uploads filter | mitigate | `isUploadsPath` on every staged path, exit 1, no override flag; design block rejects globs matching `uploads/probe.pdf` |
| T-09-07 | Tampering | `--from-zip` extraction | mitigate | Reject absolute and `..` entry names and any resolved path outside `files/` before writing |
| T-09-08 | Tampering | Symlinks in staging | mitigate | `lstatSync` walk, any symlink exits 1 |
| T-09-09 | Tampering | Truncated files near the 256 KiB cap | mitigate | Abort whole stage at >= 261120 bytes; listing size mismatch exits 1; `eof-*` HTML errors and CSS/JSX parse errors exit 1 |
| T-09-10 | Information disclosure | `design.lock.json` | mitigate | Lock schema holds sha256, byte counts, ids only; no content fields |
| T-09-11 | Denial of service | Very large zip | accept | Operator-supplied local exports only; size rule applies per file after extraction |
