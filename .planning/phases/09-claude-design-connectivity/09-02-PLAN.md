Design block shape (in `sites/<slug>/wiring.json` under `design`):
- source `design-system`: `project_id` (UUID shape, required), `name` (string, optional), `globs` (string[], optional, default DEFAULT_GLOBS)

_scripts/lib/design-lock.mjs
- `hashContent(bufOrString) -> hex sha256`; strings and text buffers LF-normalised (CRLF and lone CR -> LF) before hashing; binary buffers (contain a NUL byte) hashed raw
- `emptyLock(source) -> { version: 1, source, pulledAt: null, revision: null, files: {}, components: {}, tokens: null }`
- `readLock(siteDir) -> lock|null` reads `<siteDir>/design.lock.json`
- `writeLock(siteDir, lock)` writes 2-space JSON, keys of `files` and `components` sorted, trailing newline
- `diffFiles(prevFiles, nextFiles) -> { added, changed, removed, unchanged }` (string arrays, sorted; compare on sha256)
- `checkComponent(lock, name, currentContent|null) -> 'absent' | 'clean' | 'edited' | 'untracked'` (absent: no file on disk; clean: lock hash equals hash of current; edited: lock entry exists and differs; untracked: file exists with no lock entry)
- `recordComponent(lock, name, from, content) -> lock` sets `components[name] = { from, sha256: hashContent(content) }`

design.lock.json shape: `{ version, source: { type, id, name }, pulledAt, revision, files: { "<rel path>": { sha256, bytes } }, components: { "<Name>": { from, sha256 } }, tokens: { sha256 } | null }`

Staging layout (Claude's discretion, fixed here): `_staging/design/inbox/` is the operator's drop folder for export zips (SD-05, gitignored via `_staging/`); `_staging/design/<slug>/files/<source-relative path>` holds pulled bytes; optional `_staging/design/<slug>/listing.json` = `[{ "path": "...", "size": <int|null> }]` written by the model from `list_files` when sizes are exposed.
