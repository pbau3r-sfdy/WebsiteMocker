| Model -> staging writes | The model could alter bytes while relaying |
| Operator answers -> `--accept` | Confirmation must be per section |

| T-09-27 | Information disclosure | `uploads/**` | mitigate | Skill drops `uploads/` paths before `get_file`; `design-stage.mjs` refuses them anyway (defence in depth) |
