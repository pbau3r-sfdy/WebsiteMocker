## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator input to CLI/lib | id, slug, filenames, frontmatter are untrusted strings |
| source PDF to public site | PDF metadata can carry author, tool and attachment data |
| build output to logs | CI logs of the public repo are world-readable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Information Disclosure | PDF metadata leak | mitigate | qpdf rebuild + recursive JSON scrub + deny-list verify with negative control (Task 2) |
| T-11-02 | Tampering | path traversal via id, slug or filenames | mitigate | ID_RE, slug regex, attachment allow-list, `path.resolve` containment in listDrops, spawnSync arg arrays (Task 1/2) |
| T-11-03 | Information Disclosure | ids in logs or errors | mitigate | libs use shortId (4 chars) only; harness greps for violations (Task 1) |
| T-11-04 | Tampering | expiry bypass by hand-edited far-future date | mitigate | horizon check at build, over-horizon is invalid status (Task 1) |
| T-11-05 | Elevation of Privilege | DROPS_PREVIEW outside local sandbox | mitigate | resolveDrops throws in CI or non-sandbox base (Task 1) |
| T-11-SC | Tampering | package installs | accept | no npm packages added; qpdf is a distro/Homebrew system package, not a registry dependency; no npm PDF library may be added |
