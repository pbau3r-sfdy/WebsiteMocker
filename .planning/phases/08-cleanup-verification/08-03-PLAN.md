<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| contributor markdown -> Astro build | blog `.md` frontmatter and body cross into the build and into generated HTML |
| frontmatter `image` value -> `<img src>` | a contributor-supplied string is interpolated into a BASE_URL-prefixed image src by `BlogCard.astro` and by the detail page |
| verification harness -> phase gate | `verify-phase-08.sh hsk01` is the automated proof that HSK-01 shipped |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-10 | Tampering | blog frontmatter reaching route props | mitigate | `blogSchema` Zod validation fails the build on a missing `title`, `date`, or `summary`; `z.coerce.date()` normalises the date string |
| T-08-11 | Injection | frontmatter `image` interpolated into `src={`${b}${image}`}` | mitigate | Astro HTML-escapes attribute interpolation, so a quote-breakout is not possible; the stub post omits `image` entirely, and the schema types it as an optional plain string used only as a path suffix |
| T-08-12 | Elevation of privilege | markdown body rendered by `render(entry)` | accept | Same trusted-author model as plan 08-02: raw HTML in `.md` is permitted by Astro, authors are named org members, and `content-sync.yml` never publishes — the operator reviews before `/wm-publish`. Documented, not mitigated in code, this phase. |
| T-08-13 | Repudiation | weakening `hsk01` assertions to force a green run | mitigate | The action names the load-bearing assertions that may never be relaxed, and Task 2 requires `git diff --stat` proof that Nav and the three other active sites were untouched |
| T-08-SC | Tampering | npm/pip/cargo installs | mitigate | This plan installs no packages. `npm run build` and `npx astro build` resolve only what the existing workspace lockfile already pins; no new dependency enters the tree, so no package legitimacy checkpoint is required. |
</threat_model>
