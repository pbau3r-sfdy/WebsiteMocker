## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator → artifact HTML | Operator pastes or references HTML; content is operator-controlled |
| slug CLI arg → file system | Slug determines write paths; must be validated before any path join |
| artifact HTML → generated .astro | Artifact CSS and HTML content is embedded in output files |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Tampering | slug CLI arg → join(ROOT,'sites',slug) | mitigate | Validate slug against /^[a-z0-9-]+$/ before any path join; fail() with clear message if invalid |
| T-05-02 | Denial of Service | base64 data:image URIs | accept | Sandbox use; operator controls input; log size warning if base64 payload >500KB |
| T-05-03 | Tampering | <script> tags in artifact HTML | accept | Astro treats inline script in .astro as client-side JS; not executed server-side; no eval; acceptable |
| T-05-04 | Information Disclosure | artifact path outside _captures/ | mitigate | Artifact is always read from join(ROOT,'_captures',slug,'raw','artifact.html') — path is constructed, never taken from user input |
| T-05-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this phase; all parsing uses existing Astro transitive deps (hast-util-from-html@2.0.3 confirmed) |
</threat_model>
