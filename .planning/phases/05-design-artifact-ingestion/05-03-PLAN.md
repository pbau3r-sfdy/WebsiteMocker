    CHANGE A — Add url() rewrite pass at the end of extractScopedCSS:

    Find the `return rules.join('\n');` line at the end of the `extractScopedCSS` function. Replace it with:

    ```
    const raw = rules.join('\n');
    // Rewrite local absolute url() paths to BASE_URL template literal pattern.
    // Skip external (http/https) and embedded (data:) URIs — only absolute local paths starting with /.
    const rewritten = raw.replace(
      /url\(['"]?(\/[^'")]+)['"]?\)/g,
      (_match, path) => `url(\`\${b}${path}\`)`
    );
    return rewritten;
    ```

    The regex `url\(['"]?(/[^'")]+)['"]?\)` matches:
    - `url(/images/bg.jpg)` — unquoted local absolute path
    - `url('/images/bg.jpg')` — single-quoted local absolute path
    - `url("/images/bg.jpg")` — double-quoted local absolute path

    It does NOT match `url(https://...)`, `url(http://...)`, or `url(data:...)` because those do not start with `/` as the capture group requires.

    Do not change any other part of extractScopedCSS.

    CHANGE B — Extend hasLocalAssets check in toAstroComponent to include scopedCSS:

    Find this line in toAstroComponent:
    ```
    const hasLocalAssets = sectionHtml.includes('{b}/');
    ```

    Replace with:
    ```
    const hasLocalAssets = sectionHtml.includes('{b}/') || scopedCSS.includes('${b}');
    ```

    This ensures that when extractScopedCSS rewrites a CSS url() reference to contain `${b}`, the component frontmatter includes `const b = import.meta.env.BASE_URL.replace(/\/$/, '');` so the template literal resolves correctly.
