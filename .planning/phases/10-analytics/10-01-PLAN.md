## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| wiring.json → inline head script | Operator-edited JSON values are interpolated into JavaScript that runs on every page |
| browser → plausible.io | Page URL, referrer and event props leave the site for a third party |
| sandbox build → production Plausible site | Sandbox traffic could pollute or leak into the production property |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Tampering | buildSnippet interpolation | mitigate | scriptId/sandboxScriptId regex ^pa-[A-Za-z0-9_-]+$, host regex https-only, every value emitted via JSON.stringify; invalid values throw |
| T-10-02 | Information disclosure | transformRequest | mitigate | Fragment stripped unconditionally; sanitised mode (default on for scriptId) drops query, masks 32-hex and 40+ token segments as _ID_, scrubs props and referrer; exclude prefixes drop the event; hashBasedRouting never emitted |
| T-10-03 | Tampering | resolveIdentity sandbox path | mitigate | Sandbox build of a scriptId site emits nothing by default; ANLY-03 throws on github.io/SANDBOX_DOMAIN in production, on sandbox:false + sandboxUsesProdId, and on sandboxScriptId == scriptId |
| T-10-04 | Repudiation | D-02 opt-in | mitigate | SANDBOX_OPT_IN_WARNING logged via logger.warn on every sandbox build with the removal instruction for Phase 12 |
| T-10-05 | Information disclosure | legacy fallback | mitigate | sanitise/exclude on a legacy (no scriptId) site throws, so a site cannot believe it is protected while script.js runs without a transform |
| T-10-SC | Tampering | npm installs | accept | No package is installed in this plan |
</threat_model>
