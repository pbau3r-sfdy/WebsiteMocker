    Create .claude/skills/wm-gen-docs.md following the wm-ingest.md structure exactly. The skill has 7 steps.

    HEADER: `# /wm-gen-docs` followed by a one-paragraph summary: "Generate a self-contained branded HTML document from a Claude Design artifact and commit it to the target production repo's `docs/` folder — no Astro build required. The target site must exist in `sites/<slug>/` with `brand.doc_tokens` populated in `wiring.json`. If `brand.doc_tokens` is absent, the script will print the suggested values from `Layout.astro` — add them to `wiring.json` before re-running."

    STEP 1 — Collect inputs:
    Ask for:
    - Target slug (must exist in sites/) — validate with `ls sites/<slug>/wiring.json`
    - Artifact — operator pastes HTML content directly in chat, OR provides a path to a .zip Claude Design export in `_captures/<slug>/raw/`
    - Optional: --name <n> — output filename slug (^[a-z0-9-]+$, default: index → writes docs/index.html per D-08/D-09)
    - Optional: --format md — also export GFM Markdown to docs/<name>.md (per DOCS-06)
    - Optional: --target-repo org/repo — override wiring.json prod_repo (must be pbau3r-sfdy/* per DOCS-05)

    STEP 2 — Validate wiring.json:
    Check three preconditions:
    - `ls sites/<slug>/wiring.json` — slug must exist
    - prod_repo must be set in wiring.json (or --target-repo provided)
    - brand.doc_tokens must be populated — run `node -e "const w=JSON.parse(require('fs').readFileSync('sites/<slug>/wiring.json','utf-8')); console.log(JSON.stringify(w?.brand?.doc_tokens))"` — if output is `undefined` or `null` or `{}`: instruct operator to add brand.doc_tokens to wiring.json first (the script will show a copy-paste suggestion if they forget and run it anyway)

    STEP 3 — Stage the artifact:
    If operator pasted HTML: write it to `_captures/<slug>/raw/artifact.html`. Create the raw/ directory if it doesn't exist. Bash: `mkdir -p _captures/<slug>/raw/` then write the file.
    If operator is using a .zip export: confirm the zip is at `_captures/<slug>/raw/<name>.zip` — the script will extract it automatically.

    STEP 4 — Dry-run preview:
    Run the script without --commit to process the artifact and print the D-06 summary:
    `node _scripts/ingest-artifact.mjs <slug> --mode docs [--name <n>] [--format md] [--target-repo org/repo] --dry-run`
    Parse and present the output to the operator — particularly: how many brand tokens were injected, the before→after values, estimated output size, target repo and path.

    STEP 5 — Confirm summary and gate (D-06 / D-07):
    Present the doc generation summary in the exact D-06 format from RESEARCH.md Pattern 7:
    ```
    ── Doc Generation Summary ─────────────────────────────────
      Brand tokens injected (N):
        --accent:       <before>  →  <after>
        --bg:           <before>  →  <after>
      Output:           docs/<name>.html:  <N> KB
      Target repo:      <org>/<repo> → docs/<name>.html
      [GFM export:      docs/<name>.md:  <N> KB]   ← only shown with --format md
    ────────────────────────────────────────────────────────────

    Proceed with commit? (y/N)
    ```
    Do NOT proceed to Step 6 until the operator explicitly types `y`.
    This confirm step is MANDATORY — it cannot be bypassed in this skill, even if there are zero token changes. (D-07)

    STEP 6 — Generate and commit:
    Re-run the script with --commit to produce the final output AND push to the target repo via gh api:
    `node _scripts/ingest-artifact.mjs <slug> --mode docs [--name <n>] [--format md] [--target-repo org/repo] --commit`
    If the command fails (e.g. gh not authenticated, prod_repo not accessible), surface the exact error and stop. Do NOT retry silently.

    STEP 7 — Report done:
    Print the committed URL: `https://github.com/<org>/<repo>/blob/main/docs/<name>.html`
    And if --format md was used: `https://github.com/<org>/<repo>/blob/main/docs/<name>.md`
    Report: brand tokens injected (count + names), output file committed, repo path.

    NOTES SECTION — `## Notes`:
    - **brand.doc_tokens must be set before running** — if absent, the script exits 1 and prints the suggested values from Layout.astro as a copy-paste snippet; add the field to `sites/<slug>/wiring.json` and re-run
    - **docs/ folder is created automatically** — the script creates `_captures/<slug>/docs/` locally and the `docs/` folder in the target repo on first commit
    - **--force is script-only, never used in this skill** — the skill always pauses for the confirm gate per D-07; --force bypasses interactive prompts in the script for scripting/CI use but is not exposed here
    - **--target-repo must be in pbau3r-sfdy/*** — the script warns if the target repo is outside the org; confirm with the operator before proceeding if the warning appears
    - **Additive only** — committing a doc does not delete other files in the docs/ folder; each --name writes a separate file; docs/index.html is the default (no --name)
    - **If gh api returns 422 Unprocessable Entity** — the SHA fetch may have failed; this is a bug in the script, not an auth issue; check that gh is authenticated with `gh auth status`
