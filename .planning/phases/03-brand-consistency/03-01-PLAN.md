## Phase Goal

**As a** site operator, **I want to** have a structured brand block in every active site's configuration, **so that** content skills can suggest brand-consistent hashtags and flag off-brand language at write time.

> Note: The ROADMAP Phase 3 goal is stated as an outcome, not a user story. This story is derived faithfully from that goal. Run `/gsd mvp-phase 3` to register the formal user story in ROADMAP.md.

<objective>
Add a minimal brand stub block to all four active site wiring.json files, and create a discoverable schema reference at _core/brand-schema.md.

Purpose: Establish the brand block as the canonical per-site brand identity store. Empty stubs are inert — content skills (added in Plan 03-03) treat all-empty arrays identically to a missing brand block, so no site behaviour changes at this step. The schema reference file makes the brand block structure discoverable by Claude.ai when operators paste their wiring.json.

Output: Four modified wiring.json files (each gains a top-level "brand" key), one new _core/brand-schema.md.
</objective>
