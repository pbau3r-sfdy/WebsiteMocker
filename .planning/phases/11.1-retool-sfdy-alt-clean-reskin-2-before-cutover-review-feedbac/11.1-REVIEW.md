# Phase 11.1: Code Review Report

**Reviewed:** 2026-10-14
**Depth:** standard
**Files Reviewed:** 8

## Summary

The jobs collection, routes, nav and footer links are cleanly gone: no dangling `jobs` route or collection references in the reviewed files. The hero text in index.astro is fine. Leftovers remain in the privacy policy, the contact page and an orphaned data module. The privacy policy still describes a recruiting process that no longer exists on the site. That is a legal-accuracy problem for a page destined for cutover.

## Critical Issues

### CR-01: Privacy policy still contains an "Applications" section for a removed feature

**File:** `sites/sfdy-alt-clean-reskin-2/src/pages/privacy-policy.astro:15`
**Issue:** With the careers section removed, the site has no application flow, yet the policy declares processing of CVs and cover letters, security-clearance notes and a six-month retention period. A privacy policy that documents processing that does not happen (or, if applications still arrive via the Careers mailbox, processing that is not described accurately) is wrong either way. It also still lists a Vilnius UAB joint-controller sentence tied to applications (line 8).
**Fix:** Decide whether applications by email remain a real channel. If not, delete the `Applications` entry from `SECTIONS` and drop the sentence "For applications to positions in Vilnius, ... is joint controller ..." from `Controller` (line 8). Section numbers and TOC are generated from the array index, so nothing else needs changing. If email applications are accepted, reword as "If you send us an application by email" and keep it.

### CR-02: Contact page advertises a Careers mailbox with no careers page

**File:** `sites/sfdy-alt-clean-reskin-2/src/pages/contact.astro:11`
**Issue:** `['Careers', 'join-the-crew@starflight-dynamics.com']` remains in the contact list although the job postings and the careers section were removed (RETL-04). Visitors are invited to apply to a function the site no longer presents, and it conflicts with the privacy policy decision in CR-01.
**Fix:** Remove the row, or keep it deliberately and align the privacy text (CR-01).
```js
const mails = [
  ['General', 'mission-control@starflight-dynamics.com'],
  ['Press', 'press@starflight-dynamics.com'],
];
```
