  D-A3  No auto-publish — the operator manually runs /wm-publish when ready.
  D-A4  Sync is additive-only.
  D-A6  content-ci.yml dispatches content-sync.yml, NOT publish.yml.
  D-B2  Tooling is idempotent — a second run skips or updates rather than erroring.
  D-B3  /wm-init-collab guides the operator through the WM_DISPATCH_PAT steps inline.

Consequence for this plan: the end-to-end success condition is NOT "the post appears live
automatically". It is "the post appears in WebsiteMocker automatically, the live site is untouched
until the operator publishes, and then it goes live". A run in which the live site changed without a
`/wm-publish` would be a FAILURE of D-A3, not a success.
</user_decisions>

| WebsiteMocker main → live site | separated by the operator's `/wm-publish`, which is itself the primary control (D-A3) |
