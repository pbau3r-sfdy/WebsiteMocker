<!-- Facts these docs must state. Authoritative — do not re-derive. -->

Two credentials, deliberately distinct:
  WM_PUBLISH_PAT   Classic PAT, `repo` scope.  Lives ONLY in WebsiteMocker Actions secrets.
                   Used by publish.yml for the checkout, the commit-back, and the JamesIves push.
  WM_DISPATCH_PAT  Fine-grained PAT, resource owner pbau3r-sfdy, repository access limited to
                   pbau3r-sfdy/WebsiteMocker, Repository permissions -> Contents: Read and write,
                   1-year expiry. Lives in EACH production repo's Actions secrets.
                   Used by content-ci.yml to POST a repository_dispatch to WebsiteMocker.

Production repo branch model (COLLAB-04):
  main      contributor surface — content/**/*.md, .github/, CONTRIBUTING.md. Default branch.
  gh-pages  built output only. Force-overwritten by every publish. Never hand-edited.

Rebuild loop (COLLAB-05):
  push content/**/*.md to prod main
    -> content-ci.yml (prod repo) dispatches event_type content-updated with {"slug": "<slug>"}
    -> publish.yml (WebsiteMocker) resolves slug, clones prod main, copies *.md into
       sites/<slug>/src/content/, commits back, builds, pushes to prod gh-pages

Production repos (all four are stage 6 at plan time):
  pbau3r-sfdy/starflight-dynamics   pbau3r-sfdy/mogwai-systems
  pbau3r-sfdy/parrot-capital        pbau3r-sfdy/crestworks
