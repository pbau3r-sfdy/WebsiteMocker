# /wm-list-news

List all news posts in this site.

## Steps

1. Read all files in `src/content/news/`.

2. For each, show:
   - Slug
   - Date
   - Title
   - Has image? (yes/no)
   - Word count (approximate)
   - Summary (truncated to 80 chars)

3. Sort newest-first.

4. Print total count at the bottom.
